NEXUSFLOW 一念流
AI Agent · 架构与通信流程动态可视化
// SYSTEM ARCHITECTURE

五层结构

前端 → Java 网关 → Python Agent → Claude，agent 反向调用 Java 内部 API 控制设备。

01
shark-vue · 浏览器前端
Vue 2.6 · Element UI · fetch + ReadableStream
三栏 UI：思考流 / 积木流 / 设备投屏。流式渲染 SSE 事件，支持取消、ask_user 回写。
AiAgentDialog.vue SSE 客户端 投屏复用
↓ HTTP/SSE · POST /shark/nexusflow/agent-generate
02
shark-server · Java 网关
Spring Boot 17 · Sa-Token · WebClient · Redisson
用户鉴权 + 日预算检查 + 设备锁；将请求透传给 Agent，回程 SSE 原样转发。同时提供 /internal/agent/* 给 agent 反向调用以操作设备（MQTT 网关）。
/agent-generate /agent-reply /agent-cancel /internal/agent/* (反向)
↓ HTTP/SSE · Bearer 共享密钥
03
nexusflow-agent · Python 智能体
FastAPI · LangGraph · langchain-anthropic
运行 LangGraph StateGraph：LLM 决策 → 工具执行 → 预算检查 → 循环。
5 个工具：resolve_package / execute_block / get_layout / ask_user / finish。
独立服务器 systemd Caddy HTTPS 隔离 LLM key
↓ HTTPS · stream API · model=claude-sonnet-4-6
04
Anthropic Claude · 大模型
claude-sonnet-4-6 · Tool Use · Streaming
每轮基于 system prompt + 历史消息 + 最新 tool_result 决定下一步动作（调哪个工具 / 终止循环）。
Tool calling流式输出
↓ 反向 · agent → /internal/agent/* → MQTT type=5002/5003/5004
05
SharkPosed · 真实 Android 设备
Magisk Module · LSPosed · system_process · Rhino JS
设备是 agent 的唯一真实信息源：包名、控件树、屏幕状态都从这里实时获取，不缓存、不预设。
PackageManager 实时查询 uiautomator dump 无须连线 系统级注入
// CORE PRINCIPLE
所有真实信息从设备来，所有真实操作在设备上做——agent 不依赖任何缓存的映射表或预设数据。 包名要用？让设备 PackageManager 查。控件树要用？让设备 uiautomator dump。这样适配新 App、版本更新、罕见应用都不用改代码。

// AGENT TOOLS

5 个工具 + LangGraph 循环

LLM 不能凭空生成积木——它必须通过这 5 个工具与设备和服务器交互。

resolve_package(app_name)
**实时查询当前设备**已安装的应用，按 label 模糊匹配返回包名。设备没装的应用绝对不会被错误返回。找不到时返回 NOT_FOUND，LLM 应改用 ask_user。
入参app_name: "抖音"
返回"com.ss.android.ugc.aweme"
实现MQTT type=5004 → PackageManager.getInstalledPackages()
execute_block(block)
落块的唯一入口——调用即落入用户的最终积木流。先 schema 校验，再 SSE 推到前端，最后真机执行返回结果给 LLM。
入参block: { type, params }
返回"OK" 或 "ERROR: ..."
实现MQTT type=5002 (Rhino 引擎执行)
get_layout()
抓取当前设备屏幕的 UI 控件树。返回简化版 JSON（去除冗余容器、限 80 节点）控制 token。**不落块**，纯探索性查询。
入参（无）
返回{ nodes: [...], displaySize }
实现MQTT type=5003 → uiautomator dump
ask_user(question)
需要用户提供关键信息时调用（昵称、账号、确认）。SSE 推问题到前端，agent 暂停等回复（120 秒超时）。
入参question: "目标好友昵称？"
返回用户回答 / "USER_TIMEOUT"
实现asyncio.Event 双向通道
finish(summary, success)
完成生成并退出循环。LLM 必须主动调，否则跑到 max_steps 才会被强制终止（浪费 token）。
入参summary, success
返回FINISHED 字符串
效果graph 跳到 END 节点
// LANGGRAPH STATE MACHINE

Agent 循环

LangGraph 状态机：每轮 LLM 决策一次（调工具或终止），工具执行后回到决策节点，循环直到 finish 或预算耗尽。
